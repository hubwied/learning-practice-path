# Calculator

A simple calculator built with HTML, CSS, and JavaScript. It has no dependencies and no build step.

## Run

Open `index.html` in a browser.

## Features

- Addition, subtraction, multiplication, and division
- Decimal numbers, sign toggle, and percent
- Keyboard input: digits, `+ - * /`, Enter, Escape, and Backspace
- Division by zero shows an error
- `ANS` inserts the last successful result
- Memory keys `M+`, `M-`, `MR`, and `MC`, with an `M` indicator when memory is not zero
- A tape of the last 20 explicit results; click a result to insert it, or an equation to restore that operation
